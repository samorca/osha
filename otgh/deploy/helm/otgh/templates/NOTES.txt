1. Check the Helm release
-------------------------

  helm status {{ .Release.Name }} \
    --namespace {{ include "otgh.namespace" . }}

To inspect the values used by this release:

  helm get values {{ .Release.Name }} \
    --namespace {{ include "otgh.namespace" . }}

To inspect the complete rendered release:

  helm get manifest {{ .Release.Name }} \
    --namespace {{ include "otgh.namespace" . }}


2. Check the OTGH Deployment
----------------------------

  kubectl get deployment \
    {{ include "otgh.fullname" . }} \
    --namespace {{ include "otgh.namespace" . }}

To inspect the Deployment:

  kubectl describe deployment \
    {{ include "otgh.fullname" . }} \
    --namespace {{ include "otgh.namespace" . }}


3. Check OTGH Pods
------------------

  kubectl get pods \
    --namespace {{ include "otgh.namespace" . }} \
    -l app.kubernetes.io/name={{ include "otgh.name" . }},app.kubernetes.io/instance={{ .Release.Name }}

To watch Pod state:

  kubectl get pods \
    --namespace {{ include "otgh.namespace" . }} \
    -l app.kubernetes.io/name={{ include "otgh.name" . }},app.kubernetes.io/instance={{ .Release.Name }} \
    --watch
